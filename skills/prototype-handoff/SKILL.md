# Prototype Handoff

当前产品原型确认完成后：

1. 按 `references/SPEC.md` 描述页面。
2. 按 `references/GENERATE_PAGE_SPEC.md` 生成 `page-structure.md`。
3. 只生成交付文件，不修改当前原型。
